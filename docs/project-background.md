# AI4Chem 项目背景与研究目标

本项目用于《人工智能化学》课程小组作业，研究 **小样本 MACE 微调与失败感知的自适应过渡态搜索**。给定保持原子映射的反应物和产物三维结构，利用机器学习原子势搜索反应路径与过渡态候选，再用量子化学计算验证其频率、反应通道和电子能垒。研究主线是训练数据效率、实际搜索可靠性及计算成本之间的关系。

本说明整理于 2026-11-23，作为选题、实验和后续接手的共同背景。具体数值参数以对应版本的设计文档和配置为准，任务进度以结果证据和节点任务板为准。

## 选题如何收敛到当前问题

最初目标是利用可获得的算力，微调一个能用于真实化学计算的预训练模型。选定 MACE 和 Transition1x 后，先验证能量与受力推理，再比较预训练模型，并用少量反应构型进行微调。

v0.3.0 中，MH-1 用 256 条不同反应各一个构型进行短程全模型微调，选定模型在 210 条预留反应的固定 DFT 路径上，采样能垒 MAE 从 0.245429 降到 0.131641 eV。随后转向端点驱动的实际搜索，要求模型自己优化路径，并接受鞍点与双向 IRC 检查。[微调实验设计](design/finetuning.md)

v0.4.0 的十条开发反应中，原始与微调 MH-1 的模型势能面全阶段通过数分别为 7/10 和 6/10。结合固定路径精度的改善，这促使研究问题进一步聚焦到 **预测误差、初始路径与搜索控制分别怎样影响实际过渡态搜索**。两轮实验的样本和评价任务各有定义，当前证据支持继续分析这些因素的作用。[端点搜索实验设计](design/ts-search.md)

v0.5 已完成这条搜索研究。2026-11-23 用户明确希望把约两周用于提升模型，报告稍后自行撰写；11月25日再次强调，训练更好的模型是当前优先级。现阶段以通用势能模型的训练数据覆盖、有效优化设置和重复训练为主，搜索与 DFT 用来检验新模型的实际价值。已有搜索结果和失败诊断继续保留，不能用增加实验表格替代模型改进。

## 已有相近研究与本项目的位置

**Zhao 等，Advanced Science，2025。** *Harnessing Machine Learning to Enhance Transition State Search with Interatomic Potentials and Generative Models*，DOI `10.1002/advs.202506240`。该工作用端到端搜索、TS 精修和 IRC 比较七种原子势与 React-OT，已研究任务微调、能量与力误差和搜索成功之间的关系。其流程包含 YARP/GSM，模型包含 MACE-OFF23。[论文全文](https://pmc.ncbi.nlm.nih.gov/articles/PMC12442704/)

**Marks 等，arXiv，2026。** *Reliable and Efficient Automated Transition-State Searches with Machine-Learned Interatomic Potentials*，`arXiv:2604.00405`。该预印本已比较包含 MACE-OMol25 的多种势函数、FSM/CI-NEB 与后续 DFT 精修，进一步说明混合搜索工作流已有相近研究。[预印本](https://arxiv.org/abs/2604.00405)

**Achar 等，JCTC，2025。** *Reactive Active Learning: An Efficient Approach for Training Machine Learning Interatomic Potentials for Reacting Systems*，DOI `10.1021/acs.jctc.5c00920`。为反应区域采样、追加量化标签和反复训练提供参考，可用于后续数据效率扩展。[论文与开源实现入口](https://pubs.acs.org/doi/10.1021/acs.jctc.5c00920)

**Simon 等，JCTC，2026。** *An Active Learning Algorithm for Identifying Transition States on a Potential Energy Surface*，DOI `10.1021/acs.jctc.5c01811`。其 AL-NEB 通过代理势能面和主动选点降低力计算成本，为预算约束下的路径优化提供参考。[论文](https://pubs.acs.org/doi/10.1021/acs.jctc.5c01811)

本项目采用 MH-1/omol、自己的少样本微调权重及 ASE CI-NEB/Sella 实现，形成具体的模型与实现差异。贡献的论证重点放在新增研究问题、公平对照、失败解释与可复现证据。创新定位采用课程研究与方法改进的尺度，算法优先权需要进一步系统文献比较。

## 两级研究内容与创新方向

### 第一级——少样本微调的化学作用

利用预训练等变原子势和少量反应数据，研究训练规模、全模型微调与 readout-only 微调对相对能量、能垒和受力的影响。把固定路径上的预测改善与端点驱动搜索表现联系起来，调查改善来自何处、在哪些反应上仍然失败。现有 v0.2–v0.4 提供这一层的基线和证据。

### 第二级——失败感知的搜索控制

对端点、NEB、鞍点频率与 IRC 分阶段诊断，在固定预算内选择扰动初始化、增加图像或继续已有路径，并保留每次选择的依据。以两种固定模型和三种策略交叉对照，回答三个问题。

1. 固定多起点相对单起点能多找回哪些经过验证的鞍点，额外成本是多少。
2. 按失败原因选择恢复动作，相对固定多起点是否更有效率，哪些诊断会失效。
3. 微调与搜索恢复是否互补，模型势能面上的新增候选能否通过 DFT 复核。

失败诊断与自适应恢复构成本轮主要改进。主动学习、随机/均匀/TS 重点选样、多种子训练和新增损失项保留为后续研究方向，具体实验需另定数据预算与独立评价。

## 实际计算链与验收口径

```text
映射反应物 + 产物
  → 端点优化 → IDPP 初始化 → MACE CI-NEB
  → Sella 鞍点精修 → 投影 Hessian / 频率 → 双向 MLIP IRC
  → 分阶段诊断与预算内恢复 → 选定候选
  → DFT TS / 频率 → 双向 DFT IRC → 末端最小值 / 频率 / 映射连接
  → 成功率、几何、电子能垒、失败原因与成本报告
```

| 策略 | 本轮具体行为 |
| --- | --- |
| S0 单起点 | 标准十图像 IDPP，一次搜索 |
| S1 固定多起点 | 标准十图像、内部图像 RMS 0.03 Å 扰动、十四图像，验证鞍点后提前结束，最多三次 |
| S2 失败感知 | 首次与 S0 相同，再根据诊断选择恢复，最多三次，其中路径续算最多额外 250 步 |

模型势能面分别报告 `saddle_irc_verified` 与 `mlip_verified`。前者要求端点检查、鞍点收敛、一个显著虚频和双向 IRC 连接通过，后者额外要求 NEB 收敛。DFT 则独立检查完整频率、唯一负频率、双向 IRC、稳定末端和映射几何。全部负模及异常恢复证据均保留。

同一模型与反应共享端点和相同物理计算，策略各自累计理论成本，同时报告实际唯一次数、时间、图像步及每个验证鞍点的成本。S1 按固定起点顺序执行，S2 对端点失败提前结束，这一规则差异会影响成本解释。详细判据和参数见冻结的 [v0.5.0 协议](design/v0.5.0-protocol.md)。

## 当前已取得的证据

v0.1 的 CUDA 推理、v0.2 的预训练基准、v0.3 的微调、v0.4 的端点搜索与 DFT 验证均已完成。v0.5.0 已于 2026-11-23 发布，4 条开发加 12 条项目级保留反应，二模型三策略共 96 个评价单元，对应 83 次唯一搜索。[运行与版本结果](../README.md)

| 十二条保留反应 | S0 鞍点与 IRC | S1 鞍点与 IRC | S2 鞍点与 IRC | S0 / S1 / S2 全阶段 |
| --- | --- | --- | --- | --- |
| 原始 MH-1 | 3/12 | 3/12 | 3/12 | 3/12、3/12、3/12 |
| 微调 MH-1 | 5/12 | 6/12 | 6/12 | 5/12、5/12、5/12 |

微调模型的 S1/S2 找回了同一个额外候选 `rxn9456`，其 NEB 达到预算，鞍点与 MLIP IRC 通过。三条事前固定的 Gaussian 反应均完成验证，三策略共享这三个候选，九评价单元对应三个独立作业，条件电子能垒 MAE 为 0.206068 eV。该 DFT 子集覆盖 `rxn2737`、`rxn8204`、`rxn0666`。`rxn9456` 的补充验证属于后续 pilot。

当前结果呈现了成功率、NEB 收敛与计算开销的不同变化。S1/S2 在微调模型上增加一个验证鞍点，全阶段通过数维持 5/12。自适应策略的价值需要结合节省的计算、失败阶段和新增候选的 DFT 结论讨论。
