## 部署边界

- Linux x86_64 / Ubuntu 22.04 或 24.04；在 OMEN Ubuntu-24.04 WSL 验证。
- 沿用本项目 Mamba 科研环境管理方式；项目范围引导器和独立环境，
  不改变 base、默认 Python、用户 PATH、代理、驱动或系统软件。
- Python 3.12.16 与 `requirements.lock.txt` 固定现有工作依赖，CUDA 13.4
  PyTorch 必须在实际节点验收。驱动不兼容时停止并报告，不自动装驱动。
- 上传相对路径任务清单、数据和指定 foundation；计算使用官方
  `mace_run_train`。记录真实设备、版本、配置、epoch、模型和全部日志。
- 安装成功、CUDA 能量/力推理、短训练、完整研究任务和云端验收分别记账。
- Gaussian 不在公开分发包中；现有原生 Windows Gaussian 与未来 Linux
  Gaussian 二进制分别验收，不能把 WSL/Python 成功当作 Linux Gaussian 成功。
- 用户随后明确：部署目标是原生 Linux Gaussian，OMEN WSL 必须使用 Linux
  二进制完成安装和 TS/Freq/双向 IRC 验收。Windows 桥接只保留为历史编排
  诊断，不能满足本地部署门槛。用户会稍后提供 Linux g16，当前先跟进已有计算。
