# v0.6.0 pilot：额外恢复候选的 DFT 诊断和 Mac 完整链校准

## 问题与事前固定

v0.5.0 已完成发布。本轮在新目录运行两个固定任务，协议与映射输入在启动计算前
写入 `configs/v0.6.0-pilot/`。结果不回填或重写 v0.5.0 的成功率、DFT 分母和 release。

1. `rxn9456`：微调模型 S1/S2 比 S0 多恢复的唯一 holdout 鞍点，来自同一个
   fourteen-image attempt `498df471bf2dd325`。NEB 未收敛，但 MLIP 鞍点/频率/IRC
   通过。室友现有 Gaussian 16W A.03 验证其是否属于目标反应的 DFT 一阶鞍点。
2. `rxn0666`：已经 Gaussian 完整验证的正对照，用完全相同的原始 MLIP TS 初值，
   在 Mac 原生 PySCF/geomeTRIC 上执行十原子 DFT TS、频率、双向 IRC、末端优化/频率。
   用于计算能力与引擎差异校准，不算新的独立反应或 Gaussian 结果。

这是看过 v0.5.0 结果后的定向诊断，只有一个新 DFT 候选。不能据此估计一般成功率，
也不能视作未见测试集；若后续改变搜索策略，需要另定独立评价。

## 科学参数与验收

两者中性单重态、ωB97X/6-31G(d)，保持映射原子顺序。Gaussian 采用已验证的
4 线程 / 4 GB、UltraFine、SCF XQC/128 cycles、NoSymm；TS 80 步，LQA 双向 IRC
步长 5、160 点、MaxCycle 80；达到点数预算时最多从 checkpoint 延伸到 320 点。
保留已知 PESDtA 后处理错误的原始终止状态，只有先检测最小值和完成路径，再通过
独立末端 Opt/Freq 和映射端点验证，才可显式恢复。其他异常停止并保留日志。

Mac 使用项目已锁定 PySCF 2.15.1 / geomeTRIC 1.1.1、Cartesian 6D 基函数、
未剪枝 99×590 网格、SCF 1e-9 / 128 cycles，解析梯度和 Hessian。
TS 最多 80 步，最小值 100 步，IRC 每向最多 300 步、trust 0.05 Å。
一个反应的两支 IRC 同时运行，每支 4 线程 / 4000 MB；避免外层再并发三个反应。
调用公共 customengine 接口并建立 molecule topology。运行库不作本地补丁。

两引擎都要求 TS 优化收敛、完整 24 模、恰有一个负频率且小于 -50 cm⁻¹；
两向 IRC 各自收敛并连接两个不同预期端点，最小值优化收敛且完整频率无负模。
沿用 ASE 共价半径×1.2 映射键集合与逐连通片段刚体配准，最大 RMSD ≤0.5 Å。
全体系 RMSD、软负模、未收敛和错误均保存，不根据结果放宽判据。

Mac 对照另外事前设置诊断容差：TS 能量差 ≤1e-4 Ha、TS 对齐 RMSD ≤0.05 Å、
虚频差 ≤50 cm⁻¹、电子势垒差 ≤0.01 eV。对照的 Gaussian 数值在上一轮已公开，
这些容差用于检查实现，不能提供独立预测性能证据。网格与 IRC 算法并不完全相同。

## 运行、恢复与证据

- `configs/v0.6.0-pilot/protocol.json`：事前参数、选择理由和完整映射坐标。
- `scripts/run_mac_dft_chain.py`：Mac 原生完整 DFT 链，输出目录必须全新。
- `scripts/run_gaussian_chain.ps1`：可分发的原生 Windows 单反应 worker，
  WMI 创建独立 PowerShell owner，不添加全局配置或计划任务。一个候选同时仅一个 owner。
- `results/v0.6.0-pilot/`：各节点返回的原始输出、状态和统一判定；不提交运行时大文件。

Worker 的计算完成状态只表示原始阶段完成；统一几何解析后才可标记 DFT verified。
SSH 断开后必须通过新连接观察独立 owner、Gaussian 进程和增长的日志。
重试前核对 owner 及原生 Gaussian，保留旧失败，禁止覆盖正在运行的目录。
未来交接从根 AGENTS 与 `docs/coordination/README.md` 开始。

依据 PySCF 官方 geometry optimization / RKS Hessian 接口和 geomeTRIC 官方 IRC
实现构建；版本与接口以项目锁文件为准：

- https://pyscf.org/user/geomopt.html
- https://pyscf.org/_modules/pyscf/hessian/rks.html
- https://geometric.readthedocs.io/en/latest/irc.html

## 本轮专用自动接力

`scripts/continue_v06.py` 用 Mac 原有分析 .venv 运行，一次性监视已经存在的两条链，
60 秒读取一次状态；只导出终态 Gaussian 原始日志和 checkpoint，在 Mac 独立验收
并生成报告，最后停在 ready_for_review。连接失败保留错误并等待重连，最多 8 小时；
不重试计算、不修改策略、不提交或发布、不创建计划任务。通过独立会话进程启动，
PID 与状态在 results/coordination/v06。每轮只允许一个输出目录，禁止重复接力。

`configs/v0.6.0-pilot/protocol-r2.json` 在第二版计算前单独固定。仍使用同一
原始 MLIP 候选，Gaussian 重新执行 TS 和双向 LQA IRC，初始即分配 320 点，
每向总预算 320 点，步长 5，其余方法、电子态和科学验收与第一版一致。

跨引擎诊断。rxn0666 的已知 Gaussian 参考比较继续只用于正对照任务。
