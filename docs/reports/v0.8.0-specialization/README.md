# 同目标DFT的专门化专家：已完成结果

2026-11-25整理；七个模型和既定分析实际于November24 18:41Z前完成。
128条meta-development、42个化学式；它们是开发比较，不是prospective。
四个系统共享4096个唯一目标DFT标签、各40960估计总更新。所有真实规则
使用相同几何OOD门槛和同一个旧模型回退；不能免费借用新通用模型。

| 固定端点门控系统 | 能垒MAE/eV | 力分量RMSE/eV Å⁻¹ |
| --- | ---: | ---: |
| 单一通用512模型，含共同回退 | **0.106606** | **0.084442** |
| 两个通用种子成员 | 0.120572 | 0.085711 |
| 两个几何分区专家 | 0.118128 | 0.086054 |
| 两个带跨区目标数据回放的专家 | 0.108936 | 0.087206 |

固定使用新通用模型、不触发回退时，能垒MAE0.105757、力RMSE0.084082。
固定门控专家相对同规则通用系统，能垒差+0.011522eV，按化学式聚类的
95%区间[+0.002092,+0.022172]。回放改善了简单分区专家的能垒，但未
超过通用基线，力误差仍较大。不能据此宣称专门化整体有益。

五折按化学式分组的Ridge和ExtraTrees风险路由也未让专家系统超过通用
系统。通用模型加旧回退的ExtraTrees仅改善0.000738eV，95%区间
[-0.003645,+0.001496]；区间跨零，不能当作稳定的路由提升。

使用真实误差选专家的能垒oracle存在空间：普通分区专家0.079543eV，
回放专家0.077836eV，相比通用系统0.106606。两种oracle的力RMSE
分别0.087255/0.087284，高于通用系统0.084442。oracle既读取真实标签，
又有受力取舍，不代表已经可部署，也不证明换一个路由器就能得到该收益。

结论：这套端点几何分区和已试路由暂未训练出整体更强的专家系统；它不
否定其他化学专长、共同DFT适配或搜索提案之间的互补。特别是异构专家
端点搜索已有独立的正信号，见v0.7.0-diversity/search-summary.json。
推测原因必须与观察分开：数据分区不一定形成清晰专长、端点特征可能不够、
每个专家减少了训练覆盖；本次实验没有分别证明这三个因果解释。

方案见docs/design/specialization.md。summary.json保存既定分析的原值，
原始逐反应指标/选择在results/v0.8.0/development_analysis，没有重新拟合。
