## 使用与证据边界

安装依赖沿用仓库既有 MACE 0.3.17 锁环境。解压权重到上述相对路径后，
可用 ASE 的 MACECalculator 读取标准 `.model`，float64，CPU/CUDA
分别使用对应节点已验收环境。该模型覆盖本项目中性单重态CHNO反应，
目标参考为ωB97X/6-31G(d)；未经本项目核实的化学体系不能推定同样精度。

现有改进是开发集结果，2048第三个固定种子尚在计算。基础预训练重叠、公开float32源
与原始数据逐数值等价仍未解决。最终模型和评价预算冻结前不打开
prospective 64+64参考标签；独立静态路径、实际端点搜索和DFT仍分别验收。
512/1024及2048前两个种子权重已有实际结果；第三种子按真实状态标记。
